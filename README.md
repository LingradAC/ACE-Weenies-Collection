# ACE Weenies Collection

Welcome to the **ACE Weenies Collection** repository! This repository contains a curated assortment of weenies for use on Asheron's Call emulator servers. Whether you're a server admin, modder, or just a fan, this repository aims to provide useful resources for your projects.

## What Are Weenies?
Weenies are game objects in Asheron's Call, such as NPCs, items, monsters, and scenery, defined by specific data templates. These templates determine their behavior, appearance, and interactions within the game world.

## Repository Contents
This repository is organized into folders based on each server that has made their weenies public.

## Contributing
Contributions are welcome! To contribute:

1. Fork the repository.
2. Create a new branch for your changes.
3. Add your custom weenies, content, or improvements.
4. Submit a pull request with a description of your changes.

Any and all weenies are welcome! Just make sure you have permission to share them, or that you are the owner. If you see anything that shouldn't be in here or that you want removed, please open a pull request.

*Please do not flood the repository with random weenies. I will most likely approve them, but I don't need 10 terabytes of weenies sitting in my GitHub.*

## Feedback & Support
If you encounter issues or have suggestions, feel free to contact Lingrad at **lingrad.thetower@gmail.com**.

## Permissions
You are welcome to distribute, modify, and share any weenie that you find in this repository, as long as you give credit to the original server. I've tried to include various READMEs, but if you don't see one, please create a new README and include the server name.
